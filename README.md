# RentaMovil

Programa de consola desarrollado en Java para administrar el alquiler de automóviles, motocicletas y camionetas de carga.

El programa permite:

- Registrar vehículos.
- Consultar los vehículos de la flota.
- Cotizar alquileres.
- Confirmar alquileres.
- Registrar devoluciones.
- Consultar los vehículos disponibles y alquilados.
- Mostrar los ingresos acumulados.

## Requisitos

Para compilar y ejecutar el programa se necesita tener instalado:

- Java Development Kit (JDK) 8 o una versión posterior.
- Una terminal o consola de comandos.

## Archivos del programa

El proyecto contiene los siguientes archivos:

- `Vehiculo.java`
- `Automovil.java`
- `Motocicleta.java`
- `CamionetaCarga.java`
- `RentaMovil.java`
- `Main.java`

Todos los archivos deben estar guardados en la misma carpeta.

## Compilación

Abra una terminal dentro de la carpeta del proyecto y ejecute:

```bash
javac *.java
```

Este comando compilará todos los archivos Java del programa.

## Ejecución

Después de compilar, ejecute:

```bash
java Main
```

Se mostrará el menú principal del programa en la consola.

## Uso del programa

El menú presenta las siguientes opciones:

1. Registrar un vehículo.
2. Consultar la flota.
3. Cotizar o confirmar un alquiler.
4. Registrar una devolución.
5. Ver el reporte general.
6. Salir.

Ingrese el número de la opción que desea utilizar y siga las instrucciones mostradas en pantalla.

## Datos iniciales

El programa comienza con dos automóviles, dos motocicletas y dos camionetas de carga registrados. Todos los vehículos se encuentran disponibles y los ingresos acumulados comienzan en Q0.00.
